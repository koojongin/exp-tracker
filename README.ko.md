# EXP Tracker

화면에 보이는 EXP 숫자와 퍼센트를 OCR로 읽어 경험치 획득량을 계산하는 Windows 프로그램입니다.

## 다운로드

[최신 릴리스](https://github.com/koojongin/exp-tracker/releases/latest)에서 **ExpTracker-v1.9.0-windows-x64.exe**를 받아 실행하세요. Python 설치는 필요 없습니다. Windows 10/11 64비트용이며, 코드 서명되지 않은 실행 파일입니다.

## 사용 방법

1. 게임을 창 모드 또는 테두리 없는 창 모드로 실행합니다.
2. **상세설정 → 게임 창**을 선택합니다. 보이지 않으면 **새로고침**을 누릅니다.
3. **EXP 영역 지정**에서 EXP 숫자와 `[퍼센트%]`를 여유 있게 포함합니다. 게이지는 제외합니다. 레벨 숫자도 별도로 지정하거나 자동 레벨을 끄고 수동 입력합니다.
4. **인식 시험**으로 확인한 뒤 **측정 시작**을 누릅니다. 게임의 EXP·레벨 영역을 가리지 마세요.
5. **상세설정 → Language / 언어**에서 **한국어 / English**를 선택할 수 있습니다. 즉시 바뀌고 다음 실행에도 유지됩니다. 측정 중 바꿔도 세션은 초기화되지 않습니다.

메인 창에는 시작·일시정지, 초기화, 실시간 타이머, 세션 획득 EXP·%, 분당/시간당 EXP, 최근 60초 획득량, 시작·현재 EXP가 표시됩니다. 영역 지정·인식 옵션·미리보기·CSV 내보내기는 상세설정에 있습니다. 기본 창 크기는 100% 배율에서 360×440이며 모니터 DPI에 대응합니다.

## 계산 기준

- 획득률은 각 레벨 안에서 얻은 진행률을 합산합니다. 45.70%에서 시작해 다음 레벨 10%까지 올랐다면 **+64.30%**입니다.
- 일시정지·게임 포커스 이탈·20초 초과 인식 공백의 EXP는 제외합니다. 타이머는 일시정지에도 흐르고, 평균 속도는 유효 측정 시간을 기준으로 계산합니다.
- EXP 감소가 누적 획득량을 차감하지는 않습니다. 레벨업 예상 시간에는 감소를 반영한 순획득 속도를 사용합니다.
- 지원 데이터는 대상 클라이언트의 레벨 **1~99**입니다. 100레벨/MAX 표시, 한 번의 인식 사이 두 번 이상 레벨업은 지원하지 않습니다. 다른 버전은 별도의 EXP 표가 필요합니다.
- 화면 해상도나 HUD 위치가 달라지면 인식 영역을 다시 지정하세요.

OCR은 로컬에서 실행되며, 작은 화면 영역만 캡처합니다. 게임 메모리 읽기·입력 주입·후킹·화면 이미지 서버 전송은 하지 않습니다. 기본 인식 간격은 3초입니다.

설정과 CSV는 `%LOCALAPPDATA%\MapleExpMeter`에 저장됩니다. **기록 폴더**로 CSV 폴더를 열 수 있습니다. 개인 설정·로그는 저장소와 배포 파일에 포함하지 않았습니다.
